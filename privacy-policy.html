PicChallenge Privacy Policy

Last updated: October 8, 2025

Key Point: PicChallenge is a view-only photo contest browsing application. We do not collect, store, or process any personal information from users.

1. Information We Collect

PicChallenge does not collect any personal data from users. The app functions as a read-only browser for photography contests and does not require:

  • User registration or login
  • Personal information input
  • Device identification
  • Location data
  • Contact information

2. How We Use Information

Since we do not collect any personal data, we do not use personal information for any purposes. The app simply displays publicly available photography contest content.

3. Third-Party Services

The app connects to external WordPress APIs to display photo contest content. These connections are:

  • Read-only: No data is sent to the servers except standard HTTP requests
  • Anonymous: Requests do not include user identification
  • Public content: Only accesses publicly available contest information

4. Data Storage and Security

While no personal data is collected, we implement appropriate technical measures:

  • Secure HTTPS connections to external APIs
  • Local image caching for performance (no personal data)
  • No data transmission of personal information

5. Children's Privacy

Our app does not knowingly collect data from children under 13. Since we collect no data whatsoever, this policy naturally applies to all users.

6. Changes to This Policy

We may update this privacy policy occasionally. Any changes will be reflected on this page with an updated "Last updated" date. We encourage users to review this policy periodically.
