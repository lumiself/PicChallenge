PicChallenge Privacy Policy

Last updated: October 8, 2025

Key Point: PicChallenge only collects data necessary for user login functionality. We do not collect any additional personal information beyond what is required for authentication.

1. Information We Collect

PicChallenge only collects personal data necessary for user login and authentication. The app requires:

  • Email address for account creation and login
  • Password for account security
  • Basic profile information (if provided during registration)

We do not collect:

  • Device identification
  • Location data
  • Contact information beyond email
  • User-generated content

2. How We Use Information

The login data we collect is used solely for:

  • User authentication and account access
  • Account management and security
  • Personalizing the user experience within the app

We do not use personal information for marketing purposes or share it with third parties.

3. Third-Party Services

The app connects to external WordPress APIs to display photo contest content. These connections are:

  • Authenticated: API requests include user authentication tokens for personalized content
  • Secure: All data transmission uses encrypted HTTPS connections
  • Public content: Only accesses publicly available contest information

4. Data Storage and Security

While no personal data is collected, we implement appropriate technical measures:

  • Secure HTTPS connections to external APIs
  • Encrypted storage of authentication tokens
  • Local image caching for performance (no personal data)
  • No data transmission of personal information beyond login credentials

5. Children's Privacy

Our app does not knowingly collect data from children under 13. Since we collect no data whatsoever, this policy naturally applies to all users.

6. Changes to This Policy

We may update this privacy policy occasionally. Any changes will be reflected on this page with an updated "Last updated" date. We encourage users to review this policy periodically.
